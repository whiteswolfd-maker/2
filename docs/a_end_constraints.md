# A 终点硬约束与 B 空气侧密度修正

本修改保留按时间顺序训练 A、再训练 B 的结构。A 结束于现有公式定义的初始冲击波出流事件。此处实现解析模型约束，不表示其时空位置已通过 LS-DYNA 验证。

## 本次行为

- A 在当前配置/数据集给定的 `(tau_sep, Z_c)` 固定为解析产物侧 `(rho_x, u_x, P_x)`，`use_contact=True`。
- A 的两个锚点使用光滑的插值权重。即使初始点与结束点的约束包络重叠，各锚点也不被另一锚点污染；保留球心速度为零。
- B 继承 A 终点的压力和速度。空气侧密度使用有限环境压力下的理想气体 Rankine–Hugoniot 关系：

  $$\rho_{B,0}=\rho_a\frac{(\gamma_a+1)P_x+(\gamma_a-1)P_a}{(\gamma_a-1)P_x+(\gamma_a+1)P_a}.$$

  这里是绝对压力。该关系适用于本项目的初始出流匹配近似：将空气侧初始状态视为激波后匹配状态。它不是后续整个接触面上的密度演化公式，也不要求产物密度等于空气密度。

- B 的硬约束与 `AirShockICLoss` 使用同一空气密度关系；验证中检查压力/速度连续性，并单独检查空气密度的 RH 一致性。
- A、B 的训练返回值均为实际带约束的预测器。最终及 best 检查点同时保存基础权重、尺度、约束位置/数值及约束版本。评估、绘图和 B 单独训练入口均通过 `pinn.checkpoints.load_checkpoint` 恢复完整预测器。
- 固定端点与 DYNA 标签的差异作为模型/数据诊断输出，不再用这个固定值决定 A 是否学会了端点。差异超过阈值会明确报告；网络训练步数不能消除固定端点与标签的冲突。完成既定训练轮次不等于收敛。

## 旧权重与运行

旧 A 权重没有本次终点约束；旧 B 权重使用了产物密度。需要重新训练 A、B。A 训练入口发现旧快照会重新训练；仅训练 B 的入口会拒绝直接使用旧 A。旧权重仍可用于历史评估，但会显示缺少完整约束/尺度的提示，不会被宣称为修正后的模型。

在项目根目录运行原来的训练命令，例如：

```bash
python -m pinn.trainer --all --config configs/tnt_spherical_unified.yaml
```

之后使用：

```bash
python scripts/eval_unified.py
```

新检查点无需旁边的 `air_shock_hc_meta.pt`；同目录遗留的该文件不会覆盖新检查点内的约束。模型快照没有保存完整随机状态等信息，不是断点续训实现。

自定义预测脚本应使用返回的预测器：

```python
from pinn.checkpoints import load_checkpoint
predictor, metadata = load_checkpoint(path, raw_network, require_constraints=True)
rho, u, P = predictor(tau, Z)
```

`raw_network` 的架构需要与训练配置一致。仅将 `state_dict` 装入原始网络会丢失输出约束。

## 密度筛选与事件定位

现有 `sampling.rho_min_A: 100.0` 已对 A 的数据损失和边界数据损失实施密度筛选，单位 kg/m³。本次保留该设置，不将其改造成时间判据。

密度下限可以辅助排除空气样本，但存在三个限制：未反应 TNT 同样具有高密度；膨胀后的真实产物可能低于阈值；ALE 混合单元及跨界面插值可能产生中间密度。因此通过密度筛选不能证明样本位于 CJ 后，也不能证明终点时间正确。

`data/extract_d3plot.py` 已有压力阈值/空间梯度检测激波、ALE TNT 材料体积分数检测接触面的流程，并输出 `shock.csv` 与 `contact.csv`。这些可用于检查压缩空气层何时开始在空间上可分辨。要检查原始帧，考虑网格尺寸、激波厚度、输出间隔和阈值敏感性；平滑后的轨迹或更密的插值网格不能提供额外的原始时间分辨率。该可分辨事件不能未经核实直接等同于论文表 4.3 的出流时刻。

材料体积分数说明材料来源，不自动说明反应已经完成；定位 CJ 后起点还需与实际材料/燃烧模型的反应状态、压力和速度历史结合。
